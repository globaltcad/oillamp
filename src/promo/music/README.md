# The film's score

Put the piece the film is set to here, as `score.m4a` (or `score.mp3`, `score.flac`, …).
`./gradlew promo` lays it under the film; without one, the film is silent.

The film is cut to **"Recovery" by Rival Consoles** (Erased Tapes). That recording is not ours to
give away, so it is not in the repository, and git ignores every file here but this one. To publish
the film with it, ask Erased Tapes for a licence first; otherwise put a piece here that may be
used, and set `Score.BEGINS_AT` to where in it the film should begin.
